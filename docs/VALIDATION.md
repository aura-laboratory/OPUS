# OPUS v1 validation

Validation is being completed against the local implementation. Automated checks cover the Gymnasium contract, deterministic seeding, observation ownership, vector environments, typed inventory, bounded motion, closed-form energy, temporal crossing collisions, concave boundary constraints, pinhole GSD, coverage EMA/fusion, normalized rewards, recharge reservation/charging/resumption, crash penalties, PPO log probabilities and masks, time-limit bootstrapping, API training, checkpoint reload, evaluation, and ZIP export.

Measured learning, full-resolution timings, and browser workflow results will be recorded after those checks finish. Passing unit tests alone does not demonstrate effective learned coordination or operational readiness.
